Privacy Policy — GPX Street View Flythrough

Last updated: 2026-07-01

GPX Street View Flythrough is a Chrome extension that plays back a GPX route in Google Maps Street View. This policy explains what data the extension touches and where it goes.

Data the developer collects

None. This extension has no backend server, no analytics, and no crash reporting. It does not transmit any data to the developer or any third party controlled by the developer.

How your data is handled

  • GPX files: processed entirely inside your browser. The file you choose is read locally to draw the route and drive Street View navigation; it is never uploaded anywhere.
  • Settings (seconds between points, distance between points, loop toggle): stored using Chrome's built-in chrome.storage.sync, which syncs through your own Google account the same way Chrome syncs bookmarks or other extension settings. The developer has no access to this data.
  • Google Maps / Street View: the extension opens and navigates a google.com/maps tab on your behalf, using Google's publicly documented Street View URL format. That tab's use of Google Maps is governed by Google's own Privacy Policy, not by this extension.
  • Minimap tiles: the in-panel minimap loads map tile images from OpenStreetMap's tile servers (tile.openstreetmap.org) to render the route. This is a standard, anonymous image request (no account or API key involved); see the OpenStreetMap Foundation Privacy Policy.

Permissions

  • tabs — to open/find the Google Maps tab and update its URL as the route advances.
  • storage — to save your settings as described above.
  • sidePanel — to display the control panel docked in the browser window.
  • Host permission for https://www.google.com/maps* — scoped narrowly so the extension can only act on Google Maps tabs.

No other sites or data are accessed.

Changes to this policy

If this extension's data practices change, this document will be updated and the "Last updated" date above will reflect that.
